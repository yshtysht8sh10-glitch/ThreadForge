## 配布と運用ツール

配布Zipの作成やローカルアーカイブログの取り込みに使うスクリプトは `tools/` にあります。これらは配布物を作成・保守する側のツールであり、通常の利用者向けREADMEには詳しい手順を書きません。

配布Zipを作成します。

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\build_release.ps1
```

配布Zipは `release/threadforge-<version>.zip` に出力されます。Zip内は、展開して公開ディレクトリへアップロードしやすい構成になります。

ローカルアーカイブログを取り込みます。

```powershell
tools\import_local_archive.bat legacy\data
```

ローカルアーカイブインポートは `LOG_*.cgi` と参照画像を読み込みます。既存の投稿、画像、設定を削除しない非破壊インポートです。

複数の過去ログフォルダをまとめて取り込む場合は、次の専用ツールを使います。

```powershell
tools\import_threadforge_archives.bat legacy\import_data
```

このツールは配下フォルダの投稿を投稿日順に並べて取り込み、フォルダごとの規則で通常投稿/特殊投稿を判定します。

## 現在の主な機能

### 投稿と閲覧

- 一覧では親投稿を新しい順に表示し、各投稿の返信を最大10件までプレビューします。
- 親投稿はタイトル、本文、URL / HOME、投稿パスワード、画像、特殊投稿、SNS転記OFFを扱います。SNS転記OFFで投稿した場合、一覧や個別ページでは外部SNS先の行を表示しません。
- 画像は管理画面で許可された形式を使用できます。初期設定は GIF、PNG、JPEG、JPG、BMP です。
- 投稿前と編集時に、選択した画像のプレビューを表示します。
- 詳細ページでは親投稿、返信、コメントフォーム、簡単リアクションフォームを表示します。
- 一覧、検索結果、順位、ユーザー設定の「表示」リンクは、一覧画面の該当投稿位置へ移動します。
- 投稿と返信には `rev01` のような編集回数を表示し、カーソルを合わせると各編集日時を確認できます。
- 投稿画像やタイトルから詳細ページを開けます。編集モードと削除モードでは詳細ページへ遷移しません。

### コメントと簡単リアクション

- コメントでは名前、URL / HOME、本文、投稿パスワードを入力します。ログイン中は名前欄の代わりに「ひとこと」を入力します。
- ひとこと付きの名前は `ユーザー名@ひとこと` 形式で表示され、ユーザー名、`@`、ひとことを合わせて30文字までです。
- コメントと簡単リアクションの初期名は `Blank` です。
- 簡単リアクションは3種類の定型文を持ち、表示文字列と文字色を管理画面から変更できます。
- ログイン中は一覧上に3つの簡単リアクションボタンが縦並びで表示され、押すと設定済みの名前で返信します。
- 定型文の簡単リアクションは編集不可です。削除には管理者パスワードが必要です。

### 編集と削除

- 投稿とコメントは投稿時のパスワードで編集または削除できます。
- ログイン中、自分のIDで作成した投稿/コメントには編集/削除リンクを表示します。
- 投稿編集では、SNS転記OFFとSNSプレビューは表示せず、SNS側には編集内容が反映されない旨を表示します。
- 投稿を削除した場合は画面上から消え、管理者だけが復元できます。
- 親投稿を削除すると、その投稿についたコメントも非表示になります。
- 削除は内部的には `deleted_at` を設定するソフトデリートです。

### 検索と順位

- 検索ではキーワードと検索対象（全て、タイトル、本文、投稿者名）を指定できます。
- 検索条件はURLに保持され、戻る操作後も再検索しやすい状態を保ちます。
- 検索結果には画像、抜粋、作者、日時を表示します。
- 順位ではコメント数、閲覧数、簡単リアクション数、SNSリアクション数などを選択できます。
- 同じ数の投稿は同じ順位になります。
- 1位から3位までは金銀銅の表示になります。ただし0件の投稿には装飾を付けません。

### ログインとユーザー設定

- ID、ログインパスワード、名前、投稿パスワード、URL / HOME、アイコンを登録できます。
- 新規ID作成時は、登録前にID重複を確認します。
- ログイン中の投稿/返信では、保存済みの投稿パスワード、URL / HOME、アイコンを利用します。
- ユーザー設定ではプロフィール変更、ログアウト、自分の投稿/返信一覧、アナリティクス、自分の作品として登録を扱います。
- 過去投稿は「自分の作品として登録」から紐づけできます。紐づけた投稿は作品一覧や統計に含まれます。
- 自分のIDで投稿した投稿/返信は編集/削除できます。自分の作品として紐づけただけの投稿は表示と解除だけできます。
- 作者アイコンにカーソルを合わせると拡大アイコンと名前を表示し、クリックするとその作者の作品一覧へ移動します。
- 親サイトSSOを有効にした場合、親サイトから渡された短命署名トークンでログインできます。未登録IDは自動作成されます。

### アナリティクス

- アクセスカウンタを記録し、管理画面のアナリティクス項目として表示できます。
- 管理画面では投稿数、コメント数、閲覧数、簡単リアクション数、SNSリアクション数などを日/月/年の合計、平均、累積で集計できます。
- ユーザー設定内のアナリティクスでは、対象ユーザーの作品について総計、各投稿内訳、累積推移を表示します。
- 個人アナリティクスの横軸は投稿日時、内訳は投稿日付きの横棒グラフです。

### SNS連携

- X、Bluesky、Mastodon、Misskey の投稿設定を管理画面から行えます。初期状態はOFFです。
- X連携は未デバッグです。現時点では動作を保証しません。
- SNS転記は新規の親投稿作成時だけ実行します。返信と編集時はSNSへ投稿しません。
- SNSごとに転記プレビューと文字数上限を持ち、超過時は `..` で省略します。
- SNS投稿には一覧の該当投稿位置へ移動する「最新はこちら」リンクを含めます。
- 画像付き投稿は対応SNSへ画像も転記します。
- SNSリアクション数は管理画面、ローカルCron、APIキー付き外部定期実行URLから更新できます。`cron.php` はキーなしのブラウザ実行を拒否し、`cron.php?api_key=...` 付きの外部URL型Cronにも対応します。
- SNS投稿用のデフォルトハッシュタグは管理画面で編集できます。

### 管理画面

- 初回起動時はブラウザの管理画面で管理者パスワードを設定します。復旧用に `THREADFORGE_ADMIN_PASSWORD` も利用できます。
- 管理タブは、一括削除、復元/消去、保守、アナリティクス、掲示板設定、掲示板デザインの順です。
- 一括削除では管理者権限で全投稿を対象にし、投稿と返信を複数選択、または開始/終了の投稿番号で範囲指定して削除できます。親投稿を選択すると、その返信も一緒に選択されます。
- 一括削除と復元/消去では、投稿カードにチェックを付けて操作し、年月による表示期間の絞り込み、範囲指定による一括選択、選択解除、フル表示/簡易表示の切替を同じ操作感で利用できます。
- 復元/消去では選択した削除済み投稿/返信の復元、データ消去、番号ごとの完全削除を行えます。消去系操作は「消去を有効にする」をチェックした場合だけ実行できます。復元は青ボタン、消去系は赤ボタンで表示されます。番号ごと消去した親投稿は表示番号が前詰めされます。
- 保守では管理者パスワード変更、SNSリアクション更新、投稿番号の投稿日順採番しなおし、ユーザー登録情報画面への移動、フルバックアップZIPのインポート/エクスポートを行います。ユーザー情報そのものは、確認操作を経て開く専用のユーザー登録情報画面でだけ表示します。採番しなおしは投稿URLやNo表記が変わるため、実行前にフルバックアップを作成してください。
- ユーザー登録情報画面では情報編集、ログインパスワードの再設定、登録情報の消去、ユーザー番号ごとの完全削除を行えます。ユーザー一覧ではNo、名前、ログインID、作成日時、最終ログイン日時を確認できます。現在のログインパスワードは安全なハッシュ保存のため表示されません。再設定時は新しいパスワードを確認欄にも入力し、入力内容は表示切替で確認できます。消去系操作は「消去を有効にする」をチェックした場合だけ実行できます。保守に戻る操作または別タブへ移動すると、通常の保守タブ表示に戻ります。
- 掲示板設定ではHOMEリンク、取説本文、特殊投稿、親サイトSSO、SNS連携、cron、アップロード制限などを編集できます。
- DBがない初回起動時の掲示板設定は、特殊投稿OFF、一覧の並び順はNo順、SNS投稿ハッシュタグ `#art`、SNS連携すべてOFFかつ認証情報空欄です。
- 一覧では年/月を複数選択して表示期間を絞り込めます。1年1行の表示で、月は各年で横位置が揃います。投稿数は年または月にカーソルを合わせると表示されます。年だけを選ぶとその年全体、月を選ぶとその月だけが対象になり、選択した期間の総投稿数を確認できます。表示期間欄は三角ボタンで開閉できます。期間指定中の投稿は投稿日が新しい順に表示します。
- 最大アップロードサイズは管理画面ではKB単位で表示し、内部設定にはbyte換算で保存します。
- 掲示板デザインでは簡単リアクションの文字列/文字色/ボタン背景色と、背景、パネル、投稿枠、入力欄、各種ボタン、注意文、状態表示などの色を編集できます。設定可能な色はサンプル画面へ即時反映され、「編集前に戻す」で保存済み設定へ戻せます。
- 掲示板設定と掲示板デザインは、それぞれJSONでインポート/エクスポートできます。
- Web管理画面からはローカルアーカイブログを取り込みません。Git管理外のローカルアーカイブは運用バッチから非破壊インポートします。

## 取説ページの運用

- 掲示板/取説タイトルと本文は管理画面から編集できます。
- デフォルトの掲示板/取説タイトルは `ThreadForge` です。
- デフォルト本文は、管理者ではなくサイト利用者の目線で、その時点で利用できる機能を説明します。
- デフォルト本文内の `{{gdgdLabel}}` は、管理画面の「特殊投稿の表示名」に置き換えて表示されます。
- ユーザー向け機能を追加・変更したときは、`client/src/api.ts` と `server/api.php` のデフォルト取説本文もあわせて更新します。
