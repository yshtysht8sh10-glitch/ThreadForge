# 素材庫 仕様

## コンセプト

素材庫は保管と発見を目的としたファイル投稿システムです。圧縮ファイルが主役で、画像は内容を説明する位置付けです。Image Boardの投稿順・リアクション中心の設計とは異なり、用途タグと作者で整理します。

## 画面

- HOME: 管理画面で設定したURLを開きます。
- 一覧: 目次と、タグ・作者で整理した素材を表示します。
- 投稿: 圧縮ファイル、説明画像または試聴用MP3、名称、備考、作者名、タグ、利用規約を登録します。
- 削除 / 編集: 1件を選び、所有ユーザーまたは投稿パスワードで操作します。
- 取説: 管理画面で設定した文章を表示します。
- ログイン: ローカルログイン、SSO、素材庫用プロフィールを扱います。
- 管理画面: メニュー右端のリンクに見えない `■` からも開きます。

## 作者の判別

- ログイン投稿はユーザーIDでまとめ、作者名は表示ラベルとして扱います。
- IDのない既存素材・ゲスト投稿は作者名でまとめます。
- 同じ作者名でも、IDありとIDなしは別作者として表示します。
- 管理者は既存素材に作者IDを割り当て、またはIDなしへ戻せます。
- 目次にはタグと作者の双方を表示し、該当位置へ移動できます。
- 素材カードは広い画面で4列表示し、作者単位のまとまりを保ちながら空き列へ次の作者を配置します。

## 素材カードと音声

- カード内は、画像または音声、素材名、ダウンロード、サイズ/区分、利用規約、備考の順です。
- 画像は縦横比を維持し、長い素材名とファイル名は省略表示とツールチップで全文を確認できます。
- 新しく追加され、まだ回答されていない利用規約は `?` と表示します。
- 音声・ボイス素材では説明画像の代わりに複数のMP3を添付し、一覧で個別に試聴できます。
- 「上に戻る」は一覧・削除・編集画面の右下に表示します。

## 投稿とユーザー初期値

- 名称の初期値は `blank` です。
- 作者名、ファイル、投稿パスワードは赤い `*` 付きの必須項目です。
- 利用規約は初期状態ですべて○を選択します。
- ログイン後のユーザー設定で、作者名と利用規約ごとの○×を投稿時の初期値として保存できます。
- 削除・編集画面にも一覧と同じタグ・作者目次を表示します。
- 新規登録はログインID、ログインパスワード、確認入力だけを必須とし、作者名と投稿パスワードはログイン後に設定します。
- ログイン／新規登録では、チェックボックスでログインパスワードの表示を切り替えられます。

## SSO

- 管理画面の設定で親サイトSSOをON/OFFし、共有秘密鍵を設定・自動生成・コピーできます。
- SSOをONにすると、ThreadForge側の新規登録を禁止し、登録は親サイト側に一本化します。
- SSOをONにすると、ThreadForge管理画面でのユーザー情報編集・情報消去・番号ごとの完全消去を禁止します。
- SSO利用中も既存ユーザーのローカルログインと、ログイン後の素材庫プロフィール設定は利用できます。

## 管理

- 一括論理削除、復元、完全消去
- 投稿パスワード未設定または旧形式から移行した素材は、通常の削除・編集を禁止し、管理画面からのみ変更可能
- 作者ID割当
- ユーザー一覧、最終ログイン、素材数、ログインID、共通表示名、素材庫作者名、投稿パスワード、HOME、利用規約初期値、ログインパスワード、アイコンの管理
- ユーザー情報消去と番号ごとの完全消去。番号を詰め直す場合も、残る素材の作者IDを追従させる
- DBと素材ファイルのフルバックアップ・復元
- 素材数、作者数、タグ数、容量、月別登録数
- タイトル、説明、HOME、取説、整理順、上限、拡張子
- タグと利用規約の追加・編集・削除
- 灰色を基調とした標準配色と、見出し・メニュー・入力欄・各種ボタン・画像欄・補助文字・利用規約記号まで変更できる配色設定
- デフォルト戻しと編集前戻しは即時プレビューし、保存ボタンを押すまでDBへ保存しない
- 掲示板設定とデザインを、それぞれ専用JSONとしてファイルダイアログからインポート・エクスポートできる
- 旧デザインJSONに追加色が含まれない場合は標準値で補完し、そのまま読み込める
- 管理パスワード設定・変更
