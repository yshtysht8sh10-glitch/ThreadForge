# materials-library 仕様

[仕様索引へ戻る](../../SPEC.md)

## 目的

`materials-library` は制作素材提供所用のフロントです。

legacy の黒背景、淡い黄色文字、素材カードと利用条件表の雰囲気を参考にします。

## 予定機能

- 画像、エフェクト、音声、アーカイブ素材の閲覧とダウンロード
- 作者/説明文と利用条件フラグの表示
- プレビュー画像の表示
- 共通バックエンドによる編集/管理
- 他フロントから独立したDBとストレージ

## 見た目

- 黒背景
- 淡い黄色文字とセクション見出し
- 利用条件表付きの素材カード

## 現在の状態

React/Vite の初期フロントがあります。素材専用のデータ構造は設計中です。
