# 素材庫 仕様

## コンセプト

素材庫は保管と発見を目的としたファイル投稿システムです。圧縮ファイルが主役で、画像は内容を説明する位置付けです。Image Boardの投稿順・リアクション中心の設計とは異なり、用途タグと作者で整理します。

## 画面

- HOME: 管理画面で設定したURLを開きます。
- 一覧: 目次と、タグ・作者で整理した素材を表示します。
- 投稿: 圧縮ファイル、説明画像または試聴用MP3、名称、備考、作者名、タグ、利用規約を登録します。
- 削除 / 編集: 1件を選び、所有ユーザーまたは投稿パスワードで操作します。
- 取説: 管理画面で設定した文章を表示します。
- ログイン: ローカルログイン、SSO、素材庫用プロフィールを扱います。
- 管理画面: メニュー右端のリンクに見えない `■` からも開きます。

## 作者の判別

- ログイン投稿はユーザーIDでまとめ、作者名は表示ラベルとして扱います。
- IDのない既存素材・ゲスト投稿は作者名でまとめます。
- 同じ作者名でも、IDありとIDなしは別作者として表示します。
- 管理者は既存素材に作者IDを割り当て、またはIDなしへ戻せます。
- 目次にはタグと作者の双方を表示し、該当位置へ移動できます。
- 投稿数が2件以下の隣接作者は、1行に収まる範囲で横並びにします。

## 素材カードと音声

- カード内は、画像または音声、素材名、ダウンロード、サイズ/区分、利用規約、備考の順です。
- 画像は縦横比を維持し、長い素材名とファイル名は省略表示とツールチップで全文を確認できます。
- 新しく追加され、まだ回答されていない利用規約は `?` と表示します。
- 音声・ボイス素材では説明画像の代わりに複数のMP3を添付し、一覧で個別に試聴できます。
- 画面右下には常時「上に戻る」を表示します。

## 管理

- 一括論理削除、復元、完全消去
- 作者ID割当
- DBと素材ファイルのフルバックアップ・復元
- 素材数、作者数、タグ数、容量、月別登録数
- タイトル、説明、HOME、取説、整理順、上限、拡張子
- タグと利用規約の追加・編集・削除
- legacyを意識した配色設定
- デフォルト戻しと編集前戻しは即時プレビューし、保存ボタンを押すまでDBへ保存しない
- 管理パスワード設定・変更

## 配布

バージョン1.0.0は `15_materials_library/` に配置します。リリースZipには実運用のDBとアップロード済みファイルを含めません。
