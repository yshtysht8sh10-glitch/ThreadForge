# document-holder 仕様

[仕様一覧へ戻る](../../SPEC.md)

## 目的

`document-holder` は、文章、HTMLフォルダ、制作メモを投稿してサイト内で読めるように保管するドキュメントホルダーです。

`materials-library` と同じく「タグと作者名で整理する」考え方を使いますが、主役は素材ファイルではなく記事本文です。

## 一覧

- 管理画面で設定したタイトル、説明文、説明バナーを表示します。
- 説明バナーは複数登録でき、約5秒ごとに滑らかに切り替わります。
- 更新履歴は全記事を表示し、5件程度が見える高さで縦スクロールします。
- 目次は第一階層タグ、第二階層タグ、作者、記事タイトルで整理します。
- 目次の親は「タグ」または「投稿者名」を一覧画面で切り替えできます。
- 管理画面とログイン後のユーザー画面で、目次の既定表示を設定できます。
- 記事が書きかけの場合、一覧と記事内に赤い「書きかけ」表示を出します。

## 投稿

- 投稿方法は「その場で書く」と「index.html を含む zip を投稿」の2種類です。
- その場で書く場合は、本文欄で見出し、太字、リンク、表、文字色、表背景色、画像挿入をGUIで操作できます。
- 書き途中の記事はブラウザのローカルストレージに一時保存できます。
- 投稿時は第一階層タグを選択し、第二階層タグは既存選択または新規作成できます。
- 第一階層タグは管理画面からのみ追加・変更できます。
- 初期の第一階層タグは「指南」「感想文」「ドキュメント」「その他」です。

## 記事表示

- 投稿されたHTMLを画面いっぱいに表示します。
- 記事を開くたびに閲覧数をカウントし、記事内にも閲覧数を表示します。
- レガシー記事の画像やCSSは、移行時に記事ZIPへ格納しつつ、表示用HTMLへ必要な参照を埋め込みます。

## 管理

- タイトル、説明文、説明バナー、目次の既定表示、タグ、利用規約、デザインを管理できます。
- 管理画面のアナリティクスでは、全体の記事数、総閲覧数、投稿者数などを確認できます。
- ユーザー画面のアナリティクスでは、そのユーザーの投稿数と合計閲覧数を確認できます。

## レガシー移行

- `tools/migrate_document_holder_runtime.php` で旧 `04_DMF` の記事をローカル実行用DBへ移行します。
- 旧カテゴリは「指南」の第二階層タグとして移行します。
- 記事日時は元HTMLファイルの更新日時を使用します。
- 記事本体は `index.html` を含むZIPとして `storage/data/` に保存します。

## 現在の状態

React/Vite フロントエンドと共通 `material_items` API で実装済みです。
