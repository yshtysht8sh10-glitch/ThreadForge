# file-uploader 仕様

[仕様索引へ戻る](../../SPEC.md)

## 目的

`file-uploader` はファイルアップローダー用の単体フロントです。

legacy の灰色アップローダーUIをもとに、コンパクトなフォームと表の雰囲気を保ちます。

## 機能

- コメント付きファイルアップロード
- タイトル行へのHOMEリンク表示と、管理画面からのリンク先設定
- サイズ、日付、元ファイル名、ダウンロードリンク、削除操作の表示
- 削除キー/パスワードによる削除
- アップロード一覧のページング
- ファイル選択時とPHP API保存時の両方で許可拡張子を検証
- ファイル選択時とPHP API保存時の両方でファイルサイズ上限を検証
- 一括削除、復原/完全削除、設定、アナリティクス、デザイン、パスワード変更を持つ管理画面
- 設定とデザインを個別にJSONでインポート/エクスポート
- 保守タブでDB、アップロードファイル、設定、デザインを含むフルバックアップZIPをインポート/エクスポート
- デザイン設定のライブプレビューと実画面への即時反映
- デフォルトの灰色ダークテーマ、デフォルト戻し、編集前戻し
- デフォルト戻しと編集前戻しはプレビューだけを変更し、保存ボタンを押したときだけDBへ保存
- 共通 ThreadForge バックエンドの再利用
- 他フロントから独立したDBとストレージ

## 見た目

- Image Board / Materials Library と統一した灰色ダークテーマのアップロードフォームと表
- 素のHTMLに近い密度
- 装飾は控えめ

## 現在の状態

一覧の各ファイルには公開URLのコピーボタンと、Delkey照合を行う削除ボタンがあります。
スマートフォン表示では一覧をカード状に組み替え、長いコメントと元ファイル名を折り返します。

バージョン1.0.2では、アップロード/一覧API、設定可能なHOMEリンク、Delkey削除、管理画面の一括削除・復原・完全削除、設定、アナリティクス、拡張デザイン変更、設定・デザインのJSON入出力、フルバックアップZIP入出力、レスポンシブ表示、専用DBテーブルまで実装済みです。

## デザイン設定

- ページ、タイトル、表、フォーム、入力欄、リンク、主・補助・削除ボタン、タブ、状態表示、管理メッセージ、オーバーレイの色を個別に設定できます。
- 旧設定・旧デザインJSONは、新しい色項目を現在の初期値で補完して読み込みます。
