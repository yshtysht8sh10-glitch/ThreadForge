# file-uploader 仕様

[仕様索引へ戻る](../../SPEC.md)

## 目的

`file-uploader` はファイルアップローダー用の単体フロントです。

legacy の灰色アップローダーUIをもとに、コンパクトなフォームと表の雰囲気を保ちます。

## 予定機能

- コメント付きファイルアップロード
- サイズ、日付、元ファイル名、ダウンロードリンク、削除操作の表示
- 削除キー/パスワードによる削除
- アップロード一覧のページング
- 共通 ThreadForge バックエンドの再利用
- 他フロントから独立したDBとストレージ

## 見た目

- 灰色のアップロードフォームと表
- 素のHTMLに近い密度
- 装飾は控えめ

## 現在の状態

React/Vite の初期フロントがあります。バックエンド動作は共通掲示板モデルから調整中です。
