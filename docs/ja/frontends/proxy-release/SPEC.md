# proxy-release 仕様

[仕様索引へ戻る](../../SPEC.md)

## 目的

`proxy-release` は MUGEN キャラ、プラグイン、関連パッケージの代理公開用フロントです。

legacy の暗い背景と明るい緑文字の雰囲気を参考にします。

## 予定機能

- 代理公開リリース項目の投稿
- 説明文とダウンロード可能なアセットの表示
- リリース一覧と詳細表示
- 共通バックエンドによる編集/管理
- 他フロントから独立したDBとストレージ

## 見た目

- 暗い背景
- 明るい緑文字
- 読みやすさを保ちつつ legacy の雰囲気を残す

## 現在の状態

React/Vite の初期フロントがあります。リリース専用のデータ構造は設計中です。
