# proxy-release 仕様

[仕様索引へ戻る](../../SPEC.md)

## 目的

`proxy-release` は、MUGENキャラクターやステージなどの代理公開所向けフロントエンドです。投稿されたzipを保管し、タグと作者で整理して一覧表示します。データモデルと管理機能は materials-library をベースにします。

## 現在の挙動

- materials-library と同じ素材投稿APIと runtime テーブルを利用します。
- 代理公開の初期設定では、投稿ファイル形式を `zip` に限定します。
- MUGENキャラクターzipを選択すると、ブラウザ内で `.air` と `.sff` を読み取り、待機モーションGIFの自動生成を試みます。
- 説明用画像を手動選択した場合は、自動生成GIFより手動画像を優先します。
- HOME、一覧、投稿、削除、編集、取説、ログイン、管理画面は materials-library 相当の操作体系です。
- 上部メニューの `試遊` は `ログイン` の右側に表示します。
- 試遊リンク先は管理画面の設定から変更できます。URL未設定時はクリックできない無効表示にします。

## 代理公開向け設定

- legacy 代理公開データの取り込み後は、タグとして `MUGENキャラクター` と `MUGENステージ` などを使います。
- 利用規約は、動画使用、改変、AI作成、素材流用、改変物配布、2次配布など、MUGEN代理公開に必要な項目を設定できます。
- 管理画面のデザイン機能で legacy 風の緑基調へ変更できます。ただしデフォルトカラーは materials-library と同系統のグレー基調です。

## 見た目

- 一覧カードは materials-library の構成をベースにしつつ、カード外枠を抑え、説明画像がカードからはみ出して見える表示を許容します。
- メニューやフォームは他の ThreadForge フロントエンドと同じ操作感に寄せます。

## 注意

- 自動GIF生成は、WebMUGEN由来の SFF v1 / PCX パーサで読めるデータを対象にします。
- AIR/SFF の解析に失敗しても、手動で説明用画像を添付できます。
- リリースZipには runtime DB とアップロード済みファイルは含めません。
