# proxy-release 仕様

[仕様索引へ戻る](../../SPEC.md)

## 目的

`proxy-release` は、MUGENキャラクターデータの代理公開所向けフロントエンドです。
投稿されたzipを蓄積し、タグと作者で整理するため、データモデルと管理機能は
materials-libraryをベースにします。

## 現在の挙動

- materials-libraryと同じ素材投稿APIとDBテーブルを利用します。
- 代理公開所の初期設定では、投稿ファイル形式はzipを想定します。
- MUGENキャラクターzipを選択すると、ブラウザ内で`.air`と`.sff`を読み取り、待機モーションGIFの自動生成を試みます。
- 説明用画像を任意で選択した場合は、生成GIFより手動画像を優先します。
- HOME、一覧、投稿、削除、編集、取説、ログイン、管理画面はmaterials-library相当の操作体系です。
- 上部メニューに「試遊」を追加します。リンク先は管理画面の設定から変更できます。

## 見た目

- デフォルトカラーはmaterials-libraryと同じグレー基調です。
- 一覧カードはmaterials-libraryの構造をベースにしつつ、カード外枠を消し、説明画像がカード外へはみ出せる表示にします。
- legacyの緑基調デザインは、管理画面のデザイン設定で再現する想定です。初期値にはしません。

## 注意

- 自動GIF生成は、WebMUGEN由来のSFF v1/PCXパーサで読めるデータを対象にします。
- AIR/SFFの解析に失敗した場合でも、手動で説明用画像を添付できます。
