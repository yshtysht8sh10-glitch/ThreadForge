移行メモ

ローカルアーカイブログ

ThreadForge はローカルアーカイブ形式の LOG_*.cgi ファイルをインポートできます。ただし、この操作は意図的にWeb管理画面には置いていません。server/db.php の importLocalArchiveDirectory() を呼び出すローカル運用バッチ、またはローカルPHPコマンドから実行します。

既定の読み込み元:

  • data/

想定レイアウト:

data/
  LOG_009359.cgi
  LOG_009360.cgi
  DOTIMG_009359_1.gif
  DOTIMG_009360.png

インポート動作:

  • 各 LOG_*.cgi の先頭行は親スレッドになります。
  • 2行目以降はそのスレッドの返信になります。
  • 参照画像は有効なフロントエンドの server/runtime/<frontend-id>/storage/data/ へコピーします。
  • 既存DB行、アップロード画像、管理設定はリセットしません。
  • 再実行時は、名前、本文、時刻が一致する投稿と返信をスキップします。

インポートされた投稿は未知の生成済みパスワードハッシュを使います。管理は管理画面から行います。

個別環境用のローカルバッチは、プロジェクトとして配布すると決めない限りコミットしません。

フルバックアップ復元

フルバックアップZIPのインポートはローカルアーカイブインポートとは異なります。これは完全復元であり、投稿、返信、ユーザー、作品登録、アクセス履歴、画像、設定をバックアップ内容で置き換えます。ログインセッションは含めません。過去バージョンのJSON形式バックアップもインポート互換として読み込めます。

ThreadForge インスタンスを別環境へ移す場合はバックアップ復元を使います。既存掲示板へ過去ログを追加する場合はローカルアーカイブインポートを使います。

複数アーカイブフォルダの一括インポート

legacy/import_data のように複数の過去ログフォルダをまとめて取り込む場合は、専用ツールを使います。

tools\import_threadforge_archives.bat legacy\import_data

このツールは配下フォルダの LOG_*.cgi をすべて読み、親投稿の投稿日時が古い順になるようにDBへ取り込みます。返信は親投稿に紐づけて取り込みます。

フォルダごとの特殊投稿判定:

  • bbs1-999: ログ内の画像名、内部フィールド、タイトルから特殊投稿マーカーを自動判定します。
  • bbs10_DoteitaArchive_Doteita: 通常投稿として取り込みます。
  • bbs20_DoteitaArchive_gdgd: 特殊投稿として取り込みます。
  • bbsOO_DoteitaArchive: 投稿タイトルに gdgd または ｇｄｇｄ が含まれる場合だけ特殊投稿として取り込みます。

取り込みは非破壊です。名前、タイトル、本文、投稿日時が一致する親投稿、または名前、本文、投稿日時が一致する返信は再実行時にスキップします。実行前には管理画面からフルバックアップZIPを取得してください。

Migration Notes

Local Archive Logs

ThreadForge can import local archive-style LOG_*.cgi files, but this operation is intentionally kept out of the web admin screen. Run it from a local operator batch or local PHP command that calls importLocalArchiveDirectory() in server/db.php.

Default source directory:

  • data/

Expected layout:

data/
  LOG_009359.cgi
  LOG_009360.cgi
  DOTIMG_009359_1.gif
  DOTIMG_009360.png

Import behavior:

  • The first line of each LOG_*.cgi file becomes a top-level thread.
  • Later lines become replies under that thread.
  • Referenced images are copied into the active frontend's server/runtime/<frontend-id>/storage/data/.
  • Existing DB rows, uploaded images, and admin settings are not reset.
  • Re-running the import skips already imported posts and replies by name, content, and timestamp.

Imported posts use generated unknown password hashes. Manage them through the admin screen.
The local batch used for an individual deployment should not be committed unless the project explicitly decides to ship one.

Full Backup Restore

The full backup ZIP import is different from local archive import. It is a full restore and replaces posts/images with the backup contents. Legacy JSON backups from earlier versions remain import-compatible.

Use backup restore when moving a ThreadForge instance. Use local archive import when adding historical logs to an existing board.
