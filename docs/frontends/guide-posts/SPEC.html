guide-posts 仕様

仕様索引へ戻る

目的

guide-posts は MUGEN やドット絵制作指南を投稿するためのフロントです。

legacy の白い本文領域、青緑系ヘッダー、ナビゲーションの多い構成を参考にします。

予定機能

  • ガイドページ/記事形式の投稿
  • 多数の記事を扱うメニューやサイドバー
  • ガイド本文内または添付としての画像利用
  • 共通バックエンドによる編集/管理
  • 他フロントから独立したDBとストレージ

見た目

  • 白い記事領域
  • 青緑/青系のヘッダーとメニュー
  • 掲示板よりも情報サイト寄りの密度

現在の状態

React/Vite の初期フロントがあります。記事専用のデータ構造は設計中です。

guide-posts Spec

Back to specification index

Purpose

guide-posts is the MUGEN and dot-art production guide posting frontend.

It is based on the legacy guide site with a white content area, teal header, and navigation-heavy layout.

Planned Behavior

  • Post guide pages or article-style entries.
  • Render a menu/sidebar suitable for many guide pages.
  • Support images inside or attached to guide content.
  • Keep editing and moderation compatible with the common backend.
  • Keep runtime DB and storage isolated from every other frontend.

Visual Direction

  • White article canvas.
  • Teal/blue header and menu accents.
  • Information-site density rather than board density.

Current Status

Initial React/Vite frontend exists. Article-specific data behavior is still being designed.
